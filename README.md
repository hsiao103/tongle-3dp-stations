# 3DP同樂製造｜3DP工作平台學習

單一 HTML、不連外部資源的 3D 列印教學闖關機關，兩關串接。

| 檔案 | 內容 |
|---|---|
| `index.html` | 入口頁，連到兩關 |
| `level1.html` | 第一關：3DP 實務小常識（守護機器人重生計畫） |
| `level2.html` | 第二關：運作流程（校園公仔誕生記，7 步＋列印前檢核） |
| `docs/art-spec.md` | 美術素材需求書（給 AI 產圖用） |

## 設定
各檔案最上方的 `CONFIG` 可調整：過關代碼、關主 PIN、冷卻時間、鎖機次數、題目與教學用設定值。
活動前請務必更換預設的組別代碼與關主 PIN（程式原始碼是公開的）。

## 自動測試
網址加上 `?test=1` 會顯示自動測試結果（目前兩關各 59 項）。
