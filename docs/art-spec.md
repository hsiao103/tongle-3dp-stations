# 3DP 闖關機關｜美術素材需求書（給 ChatGPT 產圖用）

> 適用：第一關「3DP 實務小常識」、第二關「運作流程」兩個單檔 HTML 機關。
> 目前畫面是程式畫的（SVG／CSS 3D），功能完整；本文件是要把畫面升級成「插畫質感」所需的圖檔清單。
> 圖做好後，請依【第 6 節】的檔名打包交回，由我把圖接進 HTML（保留程式畫的版本當備援，圖缺了也不會壞）。

---

## 1. 使用方式（給你）

1. 先把【第 2 節 全域風格】整段貼給 ChatGPT，要它「記住這個風格，之後每張圖都套用」。
2. 再逐張貼【第 4、5 節】各素材的「提示詞」。一次一張，滿意再下一張。
3. 每張都要求：**透明背景 PNG、不要任何文字、不要浮水印**（中文字由網頁疊上去，AI 畫的字會是亂碼）。
4. 同一角色（機器人、公仔）請用同一個對話連續產，才會長得一致；第一張定稿後，後面都說「依照第一張的角色設計」。
5. 完成後依【第 6 節】命名，壓成一個 zip。

優先順序（時間不夠就先做這些）：**★必要 → ☆建議 → ○加分**。

## 2. 全域風格（貼給 ChatGPT 的第一段話）

```
請記住以下美術風格，之後我會要你產生一系列遊戲用素材，全部都要套用：

- 風格：可愛的「玩具質感 3D 插畫」（soft 3D toy render / isometric clay look），
  圓角、厚實、有一點塑膠光澤，色塊乾淨，不要寫實照片感。
- 主題：校園創客教室裡的 3D 列印工作站，適合國小中高年級，明亮、友善、不暗黑、不恐怖。
- 配色：以深海軍藍 #0A1A33／#13233F 為底，主色橘色 #FF8A1F，輔色天藍 #5AA9FF、
  螢光綠 #39FF88、琥珀黃 #FFD24D、警示紅 #FF4D5E，白色高光。
  （介面是深藍色，素材邊緣要在深藍底上清楚好看。）
- 線條：外圍有 3~4px 的深藍色描邊或明顯的輪廓，縮小到 128px 還能辨識。
- 背景：除非特別說明，一律「完全透明背景」的 PNG。
- 嚴禁：任何文字、數字、標誌、品牌、浮水印；不要出現任何現有遊戲、動漫或企業的角色與商標。
- 一致性：同一個物件在不同圖裡，形狀與配色要一致。
```

## 3. 技術規格（共通）

| 項目 | 要求 |
|---|---|
| 格式 | PNG，透明背景（除非標註「含背景」）；色彩 sRGB |
| 檔案大小 | 單檔 ≤ 250 KB，全部合計 ≤ 4 MB（因為會內嵌進單一 HTML，太大手機會慢）。請用 tinypng 等壓縮 |
| 尺寸 | 依各素材標示；請產出 2 倍大小也可，我會縮 |
| 留白 | 物件四周留約 5% 透明邊，不要貼邊裁切 |
| 方向 | 光源從左上；物件地面陰影請畫在物件內，不要另外一張 |
| 不要 | 文字、數字、浮水印、棋盤格假透明（要真的透明） |

## 7. 交件格式與命名

- 全部放進一個資料夾 `art/`，壓成 `art.zip`。
- 檔名**完全照本文件**（小寫、底線、`.png`），不要改名；缺的就缺，不要用別的名字替代。
- 若有「同一角色多張」，請確認它們看起來是同一隻（帽子、衣服顏色、五官位置一致）。
- 回傳時請附一張「全部縮圖總覽」方便我檢查。

## 8. 之後我這邊會做什麼（供你心裡有數）

1. 在兩個 HTML 的 CONFIG 加一個 `art` 區：每個素材一個 key，有圖就用圖，沒有就用目前程式畫的版本。
2. 圖會用 base64 內嵌，維持「單一 HTML、不連外部資源」，所以請守住第 3 節的檔案大小。
3. 目前 3D 公仔與機台是 CSS 立體方塊拼成的，**不是**直接貼圖。圖檔會用在：卡片插圖、角色呈現（過關畫面、診斷圖）、圖示、背景與印章。3D 場景本身若要改成貼圖質感，另外評估（工作量較大）。
4. 學生看不懂的圖寧可不要：**教學重點（45° 懸空、細腳 vs 寬底座、磁吸板有沒有吸好）一定要一眼看懂**，比好看重要。

## 9. 不能做的事（版權與安全）

- 不要要求 ChatGPT「畫成某某遊戲／動漫的樣子」，也不要貼 Steam 遊戲截圖當參考；風格一律用本文件的原創描述。
- 公仔若要用「同樂小將」，請改貼你們自己的角色設定圖當參考，並確認那些圖本身的使用權在學校手上。
- AI 產圖請保留生成紀錄；正式印刷或公開發布前，建議校內再確認一次授權與使用條款。
